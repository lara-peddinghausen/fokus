# Fokus

Um aplicativo móvel de gerenciamento de tempo baseado na técnica Pomodoro, desenvolvido com **React Native** e **Expo** durante um curso da **Alura**. 

## Características

- **Sessão de Foco**: 25 minutos de concentração total
- **Pausa Curta**: 5 minutos para descanso rápido
- **Pausa Longa**: 15 minutos para descanso profundo
- **Timer Interativo**: Play, pausa e reset com interface intuitiva
- **Gerenciamento de tarefas**: criação, edição e exclusão de tarefas
- **Persistência local**: salvamento automático com AsyncStorage
- **Drawer Navigation**: navegação lateral entre telas
- **Context API**: gerenciamento global de estado das tarefas

## Tecnologias

- JavaScript
- React Native 0.81.5
- Expo ~54.0.33
- Expo Router (navegação file-based)
- React Navigation
- AsyncStorage
- Context API

## Pré-requisitos

- Node.js v18+
- npm ou yarn
- Expo CLI

## Crédito

Este projeto foi iniciado durante o curso **"React Native: desenvolvendo com Expo"** da Alura.

Além das funcionalidades desenvolvidas em aula, foram implementadas melhorias e funcionalidades adicionais de forma independente, como o fluxo de edição de tarefas.
